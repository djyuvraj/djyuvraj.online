# DJ Yuvraj Jaipur Website

Static GitHub Pages-ready website for `djyuvraj.in`.

## Files

- `index.html` - homepage content and SEO tags
- `styles.css` - responsive design
- `script.js` - mobile menu and WhatsApp booking form
- `assets/hero-dj-yuvraj.png` - generated hero image

## How to use on GitHub Pages

1. Open your website repository on GitHub.
2. Upload/replace these files in the root of the repo.
3. Keep the `assets` folder with `hero-dj-yuvraj.png`.
4. Go to Settings > Pages and confirm the site is publishing from the main branch.

## Important edits

Update these links before final publishing:

- WhatsApp number in `index.html` and `script.js`
- Instagram URL
- YouTube URL or exact video links
- Google Drive presskit URL
- SoundCloud URL
- Email address
